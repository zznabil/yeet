# Design sources

Independent rewrite. Ideas absorbed; no reference skill, hook or runtime required.

- [OpenSpec](https://github.com/Fission-AI/OpenSpec): observable requirements and scenarios; retain specs, drop phase machinery.
- [unlazy](https://github.com/Leonxlnx/unlazy): evidence before completion, complete outcome coverage and integration checks; no gate runner or hook.
- [plow-ahead](https://github.com/BuilderIO/skills/tree/main/skills/plow-ahead): reversible defaults, routine autonomy and real blocker escalation.
- [Lean Agent Skills](https://github.com/zznabil/lean-agent-skill-collection): local source collection reviewed read-only. Absorb execution, bounded repair, research, planning, context, review, testing, release, architecture, browser/document checks, teaching, clarification, handoff and concise terminology. No skill router or mandatory companion stack.

- [vähän](https://github.com/zznabil/vahan): answer-first order and visuals-over-prose rule; no separate global `CLAUDE.md`. Source repo unchanged.

Terminology/style influences: ASD-STE100, plain language, ISO 704, Nordterm 8, OBO Foundry Principles and ANSI/NISO Z39.19. Inspiration, not certification.
