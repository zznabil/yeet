# Reference

| Area | Rule |
|---|---|
| Language | ASD-STE100: short active sentences, one action each |
| Terms | ISO 704: one term per concept, define once |
| Structure | Diataxis: tutorial, how-to, reference, explanation. No mixing |
| Style | Extreme concision. Grammar sacrificed. No filler, recaps |
| Order | Answer first |
| Exact items | Code, commands, paths, quotes unchanged |
| Visuals | Table, diagram, chart over long text. One visual per idea |
| Exception | Text-only for short answers, code, exact values |
